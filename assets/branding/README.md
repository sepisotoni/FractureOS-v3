# FractureOS mark

Original vector monogram for this project: a curved, split F with a purple upper arm and blue lower stem, on a dark rounded tile. `fracture.svg` is the editable source. ICO and PNG are exported from it for the TomTom volume, Windows executable/tray/installer and webpage favicon. No weather or media image decoder is added to the TomTom for this mark.

`splash.bmp` is a candidate 320×240, 24-bit uncompressed startup image for TomTom's SD-root splash convention. Installed to `/mnt/sdcard/splash.bmp` on the owner’s ONE v6 after SHA-256 readback; the device restarted and FractureOS returned. The owner observed that the original TomTom startup logo still appeared; the candidate did not display during this restart. The existing SD-root `system` file was left untouched.
