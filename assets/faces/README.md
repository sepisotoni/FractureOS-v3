# FractureOS face assets

Nine editable presets reuse the owner's previous face artwork. See [format, provenance and editing instructions](../../docs/FACES.md). Font notices are retained under `licenses/`; source artwork/generators are in `sources/`; atlas SHA-256 values are in `provenance.json`.

The runtime loads one selected atlas, not the entire gallery. The old sidebar and its supporting application code are not part of these packs. Supplied presets are versioned; user edits are stored separately on the device.
