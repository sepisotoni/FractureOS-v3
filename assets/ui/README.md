# UI text atlas

`default.bin` is a 20-pixel Nunito ASCII atlas, generated from the owner’s Nunito font with Pillow. The OFL notice is in `../faces/licenses/Nunito-OFL.txt`. Format: FUI1, 95 one-byte advances (ASCII 32–126), then a 1900×24 row-major alpha image.

A private `/mnt/sdcard/fracture-v3/ui-font.bin` overrides this atlas. The owner’s SF Compact font is used locally on their device; neither that font nor its generated atlas is included in the public release.
