# FractureOS TomTom ONE v6 wallpaper pack

320x240 artwork for FractureOS-inspired TomTom ONE v6 builds.

## New ImageGen concepts
- wallpapers/ai-generated/01-purple-blue-ribbon-flow.jpg
- wallpapers/ai-generated/02-midnight-sweep.jpg
- wallpapers/ai-generated/03-dual-current.jpg

The new designs use FractureOS purple and electric blue on a near-black base. The JPGs in this repository are 320x240 device-size versions. The companion ZIP contains full-quality PNG/BMP exports and high-resolution masters.

## Earlier concepts
The five earlier concepts are archived in the companion ZIP, separate from the new ImageGen set: Aurora Rift, Midnight Circuit, Violet Eclipse, Deep Blue Minimal, and Signal Bloom.

## Removable logo
logo/fracture-symbol-overlay.svg is a standalone transparent symbol overlay. It can be left out entirely or layered at bottom-right by a future wallpaper renderer. The generated art is also available without a baked-in emblem in the companion ZIP.

## Compatibility
FractureOS v0.1.17 does not yet implement a general wallpaper importer or background selector. These assets are prepared for future wallpaper support; the current renderer cannot select arbitrary backgrounds. This commit adds artwork only and does not modify firmware or the application.
