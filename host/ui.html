Current conditions and forecast are supplied by Open-Meteo; the TomTom does not make internet requests.

Unusual weather thresholds

Thunderstorms, heavy/freezing rain and heavy snow also count. Conditions are modeled estimates, not official emergency alerts.

Data from Open-Meteo under CC BY 4.0. Default coordinates are Johannesburg; set your own location here.

Today agenda

A private, read-only calendar summary. Nothing is fetched until the TomTom Today page is open.

The URL is saved only in the host's local settings and is not included in logs. Keep any private feed URL confidential.

Shows today's upcoming event titles and start times using the host's local timezone. All-day events are labeled. Recurring events, date additions and exclusions are expanded. Event details stay on the device only while the Today page is open.

Notifications

Forwarding is opt-in. The app keeps no notification history; new text and app logos go to your paired hub and TomTom.

Quiet hours suppress automatic Windows forwarding and do not replay suppressed notifications later. Block rules take precedence; allow-list-only mode forwards nothing until an app is listed.

On Windows, automatic capture additionally requires the MSIX package with the userNotificationListener capability, Windows access consent, and forwarding enabled in the native dashboard. The Store identity, certification, signed publication, install and end-to-end checks remain outstanding. Until then, use fracture notify APP TITLE BODY or authenticated /api/notifications.

Windows media and lyrics

Share media-session details from the Windows PC without Spotify account credentials.

Keep the Windows tray app running and open Spotify. Temperature needs the official signed driver and is currently supported on x64. Lyrics use LRCLIB or the authenticated lyrics endpoint; availability varies.

TomTom audio

System-output capture is disabled until enabled. A microphone is never used.

Uses 16 kHz mono PCM in 20 ms frames. Audio is relayed in memory only; the TomTom alarm takes priority.
